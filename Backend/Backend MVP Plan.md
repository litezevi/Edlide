⚙️ Интеграция Supabase и DigitalOcean

Supabase управляет DigitalOcean API напрямую

Админская панель позволяет создавать, удалять и контролировать Droplet сервера

Supabase хранит метаданные: ID, IP, нагрузка, статус, привязанные пользователи

Droplet работает как простой прокси, без бизнес-логики

🌐 Архитектура вызовов

Вся маршрутизация проходит строго по цепочке:
Supabase → Droplet → Chutes → Droplet → Supabase

Droplet выполняет роль тупого прокси, не хранит данные, не обрабатывает логику, только перенаправляет трафик.
