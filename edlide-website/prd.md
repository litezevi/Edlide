# Product Requirements Document (PRD): Edlide Website

## 1. Обзор проекта

**Edlide** — это специализированная IDE, ориентированная исключительно на работу с Open Source моделями. Цель веб-сайта — предоставить пользователям информацию о продукте, доступ к документации, возможность скачивания дистрибутивов и управление личным аккаунтом.

## 2. Целевая аудитория

* Разработчики ИИ (AI Engineers).
* Сторонники Open Source решений.
* Исследователи данных (Data Scientists), предпочитающие локальный запуск моделей.

## 3. Информационная архитектура (Навигация)

Сайт должен иметь верхнюю панель навигации (Navbar) со следующим расположением элементов (слева направо):

| Элемент | Описание | Расположение |
| --- | --- | --- |
| **Home** | Информация о продукте (фокус на OS модели). | Слева от Docs |
| **Docs** | Техническая документация и руководства. | По центру |
| **Download** | Страница загрузки образов (Cloudflare). | Справа от Docs |
| **Account** | Личный кабинет (круглый аватар пользователя). | Крайний правый угол |

## 4. Технический стек

* **Framework:** Next.js 17 (App Router).
* **Language:** TypeScript.
* **Storage:** Cloudflare R2 / Workers (для дешевого и быстрого хранения образов).
* **Styling:** Tailwind CSS (для соблюдения чистого дизайна).

## 5. Дизайн и визуальные требования

* **Основной цвет фона:** `#0d0f14` (глубокий темный).
* **Стиль:** Премиальный, минималистичный, "не завайбкоженный" (четкие сетки, качественные отступы, продуманная типографика).
* **Footer:** В нижней части сайта справа должна быть подпись: `built with Edlide IDE`.

## 6. Функциональные требования

1. **Главная (Home):** Посадочная страница с уникальным торговым предложением (USP) — работа только с открытыми моделями.
2. **Документация (Docs):** Структурированный контент (Markdown/MDX) для быстрого старта.
3. **Загрузка (Download):** Интеграция с Cloudflare для отдачи бинарных файлов (.exe, .dmg, .appimage) с минимальной задержкой.
4. **Аккаунт (Account):** Обработка авторизации и отображение профиля.

# [Teacher Note] Создание PRD для Edlide IDE

Привет! Давай разберем, как мы спроектировали фундамент для твоего проекта. Создание качественного PRD (Product Requirements Document) — это 50% успеха разработки.

### 🎯 Почему это важно?

Мы зафиксировали ключевую особенность Edlide: **фокус на Open Source**. В мире, переполненном закрытыми API, это твое главное конкурентное преимущество.

### 🛠 Разбор технологического выбора

* **Next.js 17 & TypeScript:** Мы используем самую свежую базу. Это гарантирует типизацию (меньше багов) и отличный SEO для документации.
* **Cloudflare:** Выбор в пользу Cloudflare для хранения образов — это гроссмейстерский ход. Это значительно дешевле, чем AWS S3, и благодаря их Edge-сети, скачивание будет быстрым в любой точке мира.

### 🎨 Дизайн-код

Мы используем цвет `#0d0f14`. Это не просто "черный", это глубокий графитовый оттенок, который снижает нагрузку на глаза разработчика.

> **Совет:** Чтобы дизайн не выглядел "завайбкоженным" (то есть небрежным), используй строгую 8-пиксельную сетку для всех отступов.
