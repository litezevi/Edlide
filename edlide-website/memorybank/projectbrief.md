# Project Brief: Edlide Website

## Project Overview
Edlide is a specialized IDE focused exclusively on working with Open Source models. The website serves as the central hub for product information, documentation, software distribution, and user account management.

## Core Value Proposition
- **Open Source First**: Unlike competitors, Edlide focuses exclusively on open source models
- **Developer-Centric**: Built for AI engineers and data scientists who prefer local model execution
- **Premium Experience**: Clean, minimalist design with technical precision

## Key Features
1. **Homepage**: Product showcase with unique selling proposition (USP)
2. **Documentation**: Technical guides and getting started materials
3. **Downloads**: Binary distribution via Cloudflare R2/Workers
4. **Account System**: User authentication and profile management

## Technical Architecture
- **Framework**: Next.js 17 with App Router
- **Language**: TypeScript for type safety
- **Storage**: Cloudflare R2/Workers for cost-effective global distribution
- **Styling**: Tailwind CSS with #0d0f14 deep dark theme

## Target Audience
- AI Engineers working with open source models
- Open source advocates and contributors
- Data scientists preferring local model execution
- Developers who value transparency and control

## Navigation Structure
1. **Home** (left) - Product information
2. **Docs** (center) - Technical documentation
3. **Download** (right of center) - Software distribution
4. **Account** (far right) - User profile (circular avatar)

## Success Metrics
- Download conversion rate
- Documentation engagement time
- Account registration rate
- Community adoption in open source ecosystem
